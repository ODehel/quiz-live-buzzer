## Leçons de méthode
- **Tracer le chemin de chaque message avant d'annoncer ce qu'on verra au smoke test.** La PR #16 annonçait « Réponse envoyée » à l'écran alors que `ConnectionEventHandler` envoie tous les messages à `LcdRenderer`, dont `answer_received`, qui retombait sur « Connecté ». Le défaut a été vu à l'ouverture de cette session, en relisant le routage, pas par un test.
- **Un filtre de sortie qui supprime les lignes `FAILED` fait lire une mutation comme survivante.** Les binaires de test d'une exécution précédente restent dans le dossier de build de Claude : relire chaque verdict sur le run qu'on vient de faire.
- **Test paramétré (`TEST_P`)** pour la famille « message sans rendu », une instance par type.
