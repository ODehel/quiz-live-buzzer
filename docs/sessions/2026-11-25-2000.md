## Leçons de méthode
- Les six points ouverts consignés par #78 ont été tranchés en une session de cadrage dédiée, avant le code : le port du login et ses tests n'ont plus de trou de spécification.
- Un CA modifié en place (US-FW-007 CA-6, justification seule) garde ses tests et son statut : seule la prose change, aucune preuve n'est inventée. Les CA touchés restent « Non implémenté : écart de code » tant que le code n'a pas suivi.
- Numérotation : relire la fin du journal avant de numéroter (#78 confirmé) ; ajouter un CA à la suite (CA-12) plutôt que renuméroter.
- La décision 2 ne dit pas ce que devient le résultat d'un login abandonné par une nouvelle connexion : lu comme « jeté », comme à l'élimination, consigné en « Choix de Claude » de #79 à relire en PR.

## Prochaine cible proposée
Session de code du login non bloquant : délai de 5 s de durée totale (US-FW-005 CA-8), abandon par une nouvelle connexion ou l'élimination, `401` tardif ignoré (CA-9, CA-12), un seul login à la fois dont `token_expiring_soon` ignoré pendant le login d'ouverture (US-FW-007 CA-8), réécriture des tests de rafale de US-FW-007 CA-5 ; le compteur de CA-6 et ses tests sont gardés. D'abord le login d'ouverture, puis le renouvellement. Hub toujours sans US-021 : le bout en bout reste impossible.
