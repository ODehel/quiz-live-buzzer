## Leçons de méthode
- Un test « reste dans son mode » (l'appui de la famille d'origine part encore) est nécessaire en plus du test « ignore » : sans lui, un correctif qui désarmerait au lieu d'ignorer resterait vert.
- Les cas « même message dans le mode qu'il arme » (MCQ puis `question_choices`) n'ont pas de test : aucune différence observable avec l'ancien code, une mutation ne peut pas les distinguer.
- Une mutation qui ne compile pas laisse l'ancien binaire en place : supprimer le binaire avant chaque exécution de mutation, ou vérifier la compilation.
