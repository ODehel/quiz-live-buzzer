## Leçons de méthode
- **Ping impossible avec `HttpListener`** : le `KeepAliveInterval` fait émettre un pong non sollicité (source de référence .NET Framework, `UnsolicitedPong`), jamais un ping. Une « sonde ping » aurait en fait testé le pong, hors périmètre.
- **Un fragment tronqué ne prouve rien** : une moitié d'objet est déjà ignorée par CA-7. La sonde `l` coupe donc après un objet complet, pour que le début de fragment pris pour du texte arme visiblement le buzzer.
- Mon outil d'édition a converti `œ` en `œ` dans le script : toujours revérifier l'ASCII après une édition.
