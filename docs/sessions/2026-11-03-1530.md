## Leçons de méthode
- **Un test né vert est une spécification, pas une preuve** : les tests sur police proportionnelle sont nés verts (le code mesurait déjà en pixels). Seule la mutation a montré trois trous (égalité de hauteur, taille de coupe, mot long qui partage sa ligne).
- **Un `Write` refusé après un script externe** : relire le fichier avant de réécrire, ne jamais forcer.
- **Ne pas passer `-std=gnu++11` à un fichier gtest** (gtest veut C++14) : vérifier les headers avec un petit `.cpp` autonome.
