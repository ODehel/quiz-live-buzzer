## Leçons de méthode
- **Un test faux n'est pas un code faux** : mon assertion « aaa bbb ? cc » sur 10 colonnes était erronée (« aaa bbb ? » fait 9 colonnes et tient : rien à déplacer). Le code avait raison. Calculer l'attendu à la main, colonne par colonne, avant d'écrire l'assertion ; ici l'échec a été lu avant toute modification du code.
- **La mutation a trouvé un trou et une redondance** : l'ancre non remise à 0 après un déplacement n'était couverte par aucun test (ajouté : « aaa bbb ? ?! » sur 7 colonnes) ; la condition `anchor > 0` ne servait à rien, la garde de largeur la couvre (retirée, avec un commentaire qui dit pourquoi).
- **Le cas d'un signe en série impose un repère, pas une coupure au dernier espace** : le premier vert (couper au dernier espace) a été invalidé par `bbb » ?`, où le `»` se serait retrouvé détaché. D'où `anchor`, début du dernier mot qui n'est pas un signe.
- **Les attendus d'écran se calculent avant le smoke, et se valident sur le passé** : exécuter le calcul sur l'ancien code et retrouver ce qui a été vu à l'écran la veille donne confiance dans le calcul « après ».
- **googletest et ArduinoJson se clonent depuis GitHub dans la session** : les 226 tests se rejouent sans PlatformIO. Recette : compiler une fois `gtest-all.cc` et `gmock-all.cc`, lier `MessageDeserializer.cpp` avec chaque suite, ne pas lier `gmock_main` (chaque suite a son `main`).
