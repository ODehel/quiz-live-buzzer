## Leçons de méthode
- Un test vert ne dit rien d'un code que personne ne met à l'épreuve : la mesure d'un code sans glyphe était testée (`?`, 14 px) sans que personne ait vérifié ce que la dalle en dessine (un blanc de 7 px). Seule la lecture de LovyanGFX l'a montré, et le hub accepte les émojis.
- Une dette peut contenir un chiffre faux : « 250 `¼` : 13 lignes » était inexact pour des `¼` collés (10 lignes) et sous-estimait le vrai pire cas (16 lignes, mots de 14 `¼`). Ma première lecture (« non reproduit ») était elle-même incomplète ; une recherche sur la longueur de mot l'a corrigée.
- La maquette décidait déjà une taille unique pour les quatre cartes (#19) : ce n'était pas un trou de spécification mais un écart code / rendu cible, renvoyé à US-FW-011 sans question.
- L'accès au dossier local a été refusé : travail sur un clone de `main` (dépôt public), écriture accordée pour la PR, comme aux sessions précédentes. Le clone est `--depth 1` : `git log -5` n'est utile qu'après `git fetch --depth=50 origin main`.
- Une seule salve de quatre questions, toutes recommandées ; aucune incohérence croisée n'a demandé de seconde salve. La porte 1 a été accordée telle quelle.
