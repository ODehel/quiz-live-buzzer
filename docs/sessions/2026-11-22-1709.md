## Leçons de méthode
- L'annonce de Porte 1 (14 CA, 3 tenus, 2 en partie, 9 non implémentés, trois dettes ajoutées et huit touchées) s'est vérifiée à l'écriture : compter les CA et les dettes sur un plan écrit avant la Porte 1 évite la correction du dernier handoff.
- Un clone **anonyme en lecture** du hub passe par le proxy git alors que `WebFetch` sur GitHub est refusé : pour lire un contrat du hub, cloner à profondeur 1 plutôt que chercher une URL.
- Un nom de test abrégé par « … » (`…WithoutPlayerAnswerHasNone`) ne se retrouve pas par recherche : écrire les noms complets, comme US-FW-012.
- La sonde de mise en page chiffre les options **avant** la salve de questions : les quatre options de disposition annonçaient chacune un débordement mesuré, ce qui a rendu le choix immédiat.
