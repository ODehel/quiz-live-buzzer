## Leçons de méthode
- `HubMessage` n'expose que `Type()` : il n'y a pas de « type connu » côté désérialiseur. « Jamais ramené à un type connu » se prouve donc par l'égalité exacte avec le texte reçu, pas par un prédicat de reconnaissance. La reconnaissance reste au répartiteur (`Dispatch`).
- Le type vide est un type textuel valide pour `MessageDeserializer` (`{"type":""}` est lu, type vide) : c'est le répartiteur qui l'ignore, pas le désérialiseur. Ce n'est pas un cas de CA-7.
- Mon premier script de mutation passait une chaîne vide (mauvais indice d'argument) : le binaire périmé a affiché « PASSED » ; toujours vérifier que la mutation compile et change bien le fichier (`git diff --stat lib`) avant de lire un vert.
