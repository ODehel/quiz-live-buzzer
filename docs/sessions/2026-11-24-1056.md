## Leçons de méthode
- Un smoke test fixe un périmètre de preuve : le dire dans la spec, ligne par ligne (« établi » / « non établi »), plutôt qu'un statut global, évite de faire passer un silence pour une mesure.
- Un handoff qui dit « non aligné dans cette PR » et propose la session suivante rend la session docs triviale à cadrer.
