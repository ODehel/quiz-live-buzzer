## Leçons de méthode
- **Le test d'un cas limite de largeur se calcule avec le mesureur, pas à la main** : mon premier test de coupe fixait la largeur de zone à « mot + 1 + 2 `?` », oubliant que l'espace mesure plus d'un pixel ; il aurait échoué après le correctif pour une mauvaise raison. La largeur attendue est `measurer.Width("Brésil ??", 0)` : même source que le code testé, mais c'est la mesure elle-même qu'on veut égale à elle-même, pas un chiffre à deviner. Le test appelait aussi `Wrap` (non filtré) au lieu de `Compute` : le rouge l'a montré avant tout vert.
- **Un premier vert trop large est une bonne chose s'il est suivi de tests qui le resserrent** : le premier filtre remplaçait tout code > 0xFF ; les tests suivants (signes gardés, contrôles) l'ont fait grossir juste ce qu'il fallait. Les huit tests nés verts ne prouvaient rien seuls : d'où les 33 mutants, dont dix voisins ajoutés un à un à la liste des signes gardés.
- **Un test qui indexe `lines[0]` plante au lieu d'échouer si le vecteur est vide** (trois mutants donnaient un code 139) : `ASSERT_EQ` sur le vecteur avant l'indexation.
- **Un contrôle jetable sous ASan et UBSan pour ce que le CDC ne décide pas** : le comportement sur les octets invalides n'est pas figé en test (il n'est pas décidé), mais « ne plante pas » se vérifie sans l'écrire dans le dépôt.
- **Mon script de compilation manuelle liait `gtest_main`, pas PlatformIO** : la CI a rejeté `test_glyph_filter` (`undefined reference to main`), car chaque suite du dépôt définit son propre `main`. Corrigé par un second commit (un amendement exigeait un force push, interdit) que le squash absorbera ; le script de compilation ne lie plus `gtest_main`, les 28 suites passent ainsi (750 tests). À retenir pour la procédure du handoff `1246` : ne pas lier `gtest_main`, et toute nouvelle suite porte son `main`.
- Environnement : même procédure qu'au handoff `1246` ; script de compilation parallèle (8 jobs, ~45 s les 28 suites) et script de mutation (remplacement textuel, relance de `test_glyph_filter` et `test_text_layout`, restauration + sha256) hors dépôt, dans `/tmp/fwbuild`. Pas de `session-close.ps1` (PowerShell absent) : handoff rédigé à la main d'après le gabarit.
