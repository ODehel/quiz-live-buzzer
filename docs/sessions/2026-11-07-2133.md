## Leçons de méthode
- **Un test qui fige un texte provisoire se remplace, il ne se complète pas** : l'ancien test de `question_choices` (« Question QCM en cours » sur un message sans champ) est devenu « écran inchangé ». Le rouge était double, attendu avant de lancer.
- **« Ne pas vérifier la cardinalité » n'autorise pas l'indexation en dur** : `choices[3]` sur un tableau court est un comportement indéfini sur l'ESP32. La boucle sur les lettres tient sans vérifier, sans test de plus.
- **Un outil d'édition de texte peut convertir les `è` en vrais accents** : `fake-hub.ps1` doit rester ASCII (PowerShell 5.1 lit en ANSI). Vérification à refaire après toute édition du script : `grep -nP '[^\x00-\x7F]' scripts/fake-hub.ps1` ne doit rien renvoyer.
- **Un mutant équivalent est un signal, pas une lacune** : `HasChoices()` n'a pas de consommateur de production. Gardé par cohérence avec les autres champs ; à retirer si on préfère le YAGNI strict.
