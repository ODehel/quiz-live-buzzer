## Leçons de méthode
- Les mutations passent par `git checkout -- lib` : il faut **indexer le correctif avant** de muter, sinon la restauration revient à `main` et efface le code (le fichier de mutation a été lancé après `git add` des deux fichiers de `lib/`).
- Un `OnBuzzLocked()` vide donne un rouge de comportement propre (un seul test par couche) entre le rouge de compilation et le vert.
- Les tests de CA-9 naissent verts par construction (aucune branche avant) : leur valeur tient aux mutants M2 à M4, M6 et M7, qui sont les fautes réalistes d'un `OnBuzzLocked` trop large.
- Les tests de CA-10 du handoff précédent ont servi de filet : M9 et M10 les rendent rouges, ils ne se contentent pas de figer l'absence de branche.
