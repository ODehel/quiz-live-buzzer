## Leçons de méthode
- Niveau de preuve : `test_dispatch` plutôt que `test_connection`. Le mode et l'envoi s'observent directement sur `BuzzerBehavior` avec les mocks de `GameMocks.h`, sans rendu ni session ; la chaîne JSON vers `Dispatch` relève de CA-1 et CA-3.
- « Rien n'est envoyé par le message lui-même » se prouve en vérifiant les mocks (`VerifyAndClearExpectations`) entre le `Dispatch` et l'appui : sans cela, un `Dispatch` qui enverrait n'est pas distinguable d'un appui.
- Une mutation par famille (MCQ, SPEED, Inerte, envoi) est nécessaire : désarmer ne rougit pas la famille Inerte, armer ne rougit pas les familles armées.
