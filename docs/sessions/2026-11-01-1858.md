## Leçons de méthode
- **Vérifier ce que le hub émet avant d'écrire un scénario de smoke test.** Le scénario MCQ/SPEED était irréalisable : le hub n'envoie pas encore les messages de jeu. La cible 3 du handoff précédent (appui MCQ puis SPEED) l'était aussi.
- **`pio device monitor` refuse toute redirection** (`| Tee-Object`) : le lancer seul, sans pipe.
- **Le firmware ne journalise aucun message reçu** : le moniteur ne permet pas de savoir ce que le hub a envoyé.
- **Test paramétré (`TEST_P`)** par famille de messages : une instance par type, dans chacune des deux suites.
