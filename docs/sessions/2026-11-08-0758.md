## Leçons de méthode
- **Annuler une mutation avec `git checkout` efface le travail non commité du même fichier** : pour prouver le test du `null`, j'ai muté puis restauré par `git checkout`, ce qui a supprimé les trois lectures de `MessageDeserializer.cpp`. Vu immédiatement (le test du `null` échouait avec le mutant), rétabli à l'identique, suite complète et 11 mutants rejoués. Règle : toute mutation passe par `mutate.py` (copie en mémoire), jamais par `git checkout` tant que le commit n'existe pas.
- **Un contrat de hub lu dans les specs vaut mieux qu'une hypothèse** : le cas « MCQ sans réponse du joueur » reposait sur une supposition (champ absent). La lecture de US-011 montre `answer: null` côté base (CA-34) : le message pourrait porter `null`. Les deux cas sont traités et figés par un test chacun.
- **Les gardes de type valent test dès la lecture du champ** : les trois lectures ont chacune un test « absent » et un test « mauvais type » nés verts, prouvés par mutation (retirer la garde) plutôt que supposés.
- **`fake-hub.ps1` doit rester ASCII** : `grep -cP '[^\x00-\x7F]' scripts/fake-hub.ps1` renvoie 0 après cette session (à refaire après toute édition).
