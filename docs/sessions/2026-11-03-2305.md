## Leçons de méthode
- **Lire LovyanGFX avant de choisir le format** : `getGlyph` et `getDefaultMetric` décrivent exactement ce que fait `EncodeRange` (`base` est un indice de glyphe, `last` borne tous les codes). La lecture des plages dans `ReadFontMetrics` reprend cette recherche, pas une hypothèse.
- **Mesurer avant de craindre** : la boîte d'encre de la police (qui règle l'interligne à 90 %) n'est pas modifiée par les cinq glyphes, vérifié sur les trois polices avant de conclure.
- **Un constructeur absent est un rouge** : le premier test a échoué à la compilation, ce qui compte comme rouge ; le suivant échouait sur une valeur.
- **Le générateur n'a pas de test** : le recoupement avec FreeType est manuel, dans la session ; il n'est pas rejouable. Dette déjà connue (« Polices en 1 bit »), non soldée.
- **Environnement de session** : un `printf` dont le texte contient `%` écrit un début de fichier avant d'échouer ; vérifier `git diff --stat` après chaque ajout en ligne de commande, et préférer Python pour les textes longs.
