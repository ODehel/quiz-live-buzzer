## Leçons de méthode
- **« Rejouer sur le vrai hub » était irréalisable** : la lecture de `ws-route.ts` du hub a montré qu'il n'a aucun relais vers un buzzer. La contrainte a été posée avant d'écrire quoi que ce soit, ce qui a évité un script inutile. Option retenue avec Olivier : un faux hub qui prend la place du vrai.
- **Un `.ps1` sans BOM se lit en ANSI sous Windows PowerShell 5.1** : tout caractère non-ASCII se corrompt. Les accents des messages passent en échappements `\u` JSON, et la relecture `grep -P '[^\x00-\x7F]'` est devenue un réflexe avant commit.
- **Un script non exécutable en session doit le dire** : pas de test natif possible ici, donc la PR liste les attendus d'écran et le smoke test est la seule preuve.
