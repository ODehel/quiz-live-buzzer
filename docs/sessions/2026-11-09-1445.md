## Leçons de méthode
- Le dépôt n'avait pas de maquette ni de répertoire `docs/mockups/` : le précédent cité pour le front Angular (`quiz-buzzer-themes-list.html`) vit dans l'autre dépôt, le format a été repris sans le relire.
- Le bandeau du haut a été ajouté après la première revue d'Olivier, avant tout push : `amend` du commit unique. Il demande trois données absentes du firmware (nom du joueur, points, classement, batterie) : à cadrer avant tout `feat`.
- Une maquette qui introduit un en-tête persistant (chrono, « Question N ») change le modèle d'affichage, pas seulement le dessin : à dire dès la porte 1 quand une maquette propose un état que le firmware ne porte pas encore.
