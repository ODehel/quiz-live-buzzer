## Leçons de méthode
- Compiler les suites à la main exige googletest (`apt install libgtest-dev libgmock-dev`) et ArduinoJson (`git clone --depth 1 --branch v7.4.3` ; `codeload.github.com` renvoie un JSON d'erreur au proxy, `git clone` passe). Un script qui lance l'ancien binaire quand la compilation échoue ment : supprimer le binaire avant de compiler.
- Un nouveau port de `lib/` coûte une ligne par site de construction dans les tests (six ici) : l'ajouter à la fixture évite d'en oublier.

## Points à challenger
- Le dessin (`GfxScreen::ShowOutOfGame`, `DrawPowerRing`) n'a jamais été compilé contre LovyanGFX ni vu sur la dalle : l'anneau couvre 129 px, le symbole est approché au pinceau rond, la pile utilise les 62 et 50 px de la spec et non les hauteurs de ligne du `measurer` (64 et 50 px).
