## Leçons de méthode
- Un mock non strict ne prouve pas l'absence d'appel : chaque « ne fait rien » passe par `EXPECT_CALL(...).Times(0)` sur les quatre méthodes (deux de `HubMessageSender`, deux de `LocalFeedback`), sinon M4 restait vert (l'ancien test de CA-6 n'assertait que `SendAnswer`).
- Le test de verrou (CA-3) passe par un `LocalFeedback` réentrant (`WillOnce` qui rappelle `OnMcqPressed`) : sans lui, aucun test n'observe l'ordre verrou / feedback. M1 est le seul mutant qu'il est seul à tuer.
- Un test « reste armé » (M5) est nécessaire en plus du test « ignore » : le second ne voit pas un désarmement silencieux.
- Une mutation par fichier restauré via `git checkout` entre chaque exécution, binaire supprimé avant : aucune fausse verte par ancien binaire.
- Le décompte des suites doit venir du disque (`ls -d test/test_*`), pas du handoff : 25, pas 26.
