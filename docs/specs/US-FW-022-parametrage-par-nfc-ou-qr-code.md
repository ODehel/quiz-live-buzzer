# US-FW-022 — Paramétrage par NFC ou QR code

- **Couche** : vide
- **Statut** : Vide, bloquée
- **Dépend du hub** : —

## Périmètre

Paramétrer le buzzer depuis l'application mobile du maître du jeu : module NFC et/ou écran de configuration avec QR code (aucune consigne à l'écran, icône d'engrenage).

## Bloqué par

Canal d'appairage non décidé (BLE, point d'accès temporaire, NFC), déclencheur de l'écran, contenu réel du QR ; l'application mobile n'existe pas.

## Sources

CDC §2 (module NFC), §10 point 1 ; maquette `start-06-config` ; décision #36 ; `DEBTS.md` (« Paramétrage NFC non spécifié », « Configuration maquettée sans déclencheur, canal ni report »).
